# JMdict data

`jmdict.sqlite` is built from JMdict, the Japanese–Multilingual Dictionary, by
`Tools/build-dictionary.py`.

JMdict is the property of the Electronic Dictionary Research and Development
Group, and is used in conformance with the Group's licence:
https://www.edrdg.org/edrdg/licence.html

The database, like JMdict itself, is licensed under the Creative Commons
Attribution-ShareAlike 4.0 International licence (CC BY-SA 4.0):
https://creativecommons.org/licenses/by-sa/4.0/

This licence covers the data in this folder only. The code in this package is
licensed separately.

Apps that show definitions from it must acknowledge the source, for example
in an About screen: "This app uses the JMdict dictionary files. These files are
the property of the Electronic Dictionary Research and Development Group, and
are used in conformance with the Group's licence," with a link to
https://www.edrdg.org/. `RubyDictionary.credit` has a short form for where definitions show.
